# References

Projects and libraries useful for implementation research.

| Project                                                                      | Reference use                                                             |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| [Signal](https://github.com/ryohey/signal)                                   | Closest match: React+TS MIDI piano roll ([demo](https://signalmidi.app/)) |
| [react-midi-editor](https://github.com/chanyatfu/react-midi-editor)          | React piano roll component with selection, copy/paste, undo               |
| [webaudio-pianoroll](https://github.com/g200kg/webaudio-pianoroll)           | Standalone vanilla JS piano roll UI                                       |
| [openDAW](https://github.com/andremichelle/openDAW)                          | Full TS DAW, plugin architecture                                          |
| [GridSound](https://github.com/gridsound/daw)                                | Vanilla JS DAW, pattern sequencer                                         |
| [BeepBox](https://github.com/johnnesky/beepbox)                              | TS chiptune tracker, URL-based storage                                    |
| [waveform-playlist](https://github.com/naomiaro/waveform-playlist)           | React + Tone.js audio editing                                             |
| [AudioMass](https://github.com/pkalogiros/AudioMass)                         | Vanilla JS waveform editor                                                |
| [Tone.js](https://github.com/Tonejs/Tone.js)                                 | Audio engine internals: transport, scheduling, channels                   |
| [@tonejs/midi](https://github.com/Tonejs/Midi)                               | MIDI file read/write                                                      |
| [web-audio-worklet-rust](https://github.com/hi-ogawa/web-audio-worklet-rust) | Source of the bundled OxiSynth WASM/worklet assets                        |
| [wavelet](https://github.com/ryohey/wavelet)                                 | SoundFont synth prior art                                                 |
